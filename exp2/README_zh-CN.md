# exp2：循环最优响应可扩展性实验

## 运行

将整个 `exp1-add` 文件夹加入 MATLAB 当前目录，运行：

```matlab
results = main_scalability;
```

默认测试四种拓扑、`N=200:200:10000`、平均度6，每种配置3次独立重复，共600次求解。只输出可扩展性图，不运行攻击或系统损失实验。需要支持 `graph`、`delaunayTriangulation`、`tiledlayout` 和 `exportgraphics` 的 MATLAB；主实验不需要 Optimization Toolbox。

先检查环境和求解器可运行性：

```matlab
results = main_pilot;
```

预实验测试每种拓扑的200、1000和10000节点，各1次，30秒/200轮上限；它还使用 Optimization Toolbox 的 `fmincon` 对40个局部问题作独立对照。没有该工具箱时直接调用：

```matlab
results = main_scalability(struct('sizes',[200 1000 10000], ...
    'repetitions',1,'maxSweeps',200,'timeLimitSeconds',30, ...
    'outputDir',fullfile(pwd,'my_pilot_results')));
```

平均度敏感性实验（2400次求解）：

```matlab
results = main_scalability(struct('targetDegrees',[2 4 6 8], ...
    'outputDir',fullfile(pwd,'degree_results')));
```

增加求解上限、独立重复次数：

```matlab
results = main_scalability(struct('repetitions',5,'maxSweeps',2000, ...
    'timeLimitSeconds',600,'outputDir',fullfile(pwd,'extended_results')));
```

相同配置可自动断点续算；修改计算配置后请更换 `outputDir`，或指定 `resume=false`。默认文件中断后保留已完成案例。`replot_figures('结果目录')` 只重新绘图。

## 与原实验的关系

成本效用 `U_i=sum_j SL_j*log(1+s_j)`，其中 `s_j=sum_i a_ij*x_ij`。资源约束为每个节点的非负分配之和不超过其容量。总安全效用为 `sum_j SL_j*log(1+s_j)`，不是对所有个体效用再求和。每轮按照固定节点顺序依次更新，后续节点使用最新结果。

本实验只评估 GRA 的循环最优响应求解过程。为避免通用优化器启动与线性代数开销掩盖算法规模特性，局部对数凹问题使用排序水位法求解，与原局部优化问题数学等价；没有改变效用、资源约束或外层更新顺序。不能把这里的速度直接描述成原始 NIRA 或原始 fmincon 实现的实测速度。

对当前节点，令 `b_j=1+s_j-a_ij*x_ij`，局部解为 `z_j=max(0,SL_j/lambda-b_j/a_ij)`。按 `SL_j/(b_j/a_ij)` 排序确定活动集合，并使资源约束取等号。正权重保证此局部问题具有唯一解。仅在浮点误差造成轻微超配时缩放到可行域。

## 网络设计：明确改变原始生成规则

固定200×200区域和30米半径不能同时实现节点规模增长和稀疏平均度。本实验保留四种空间分布类型，采用随 `sqrt(N)` 扩大的空间尺度；在 Delaunay 及其二跳空间候选边中加入最小生成树骨架，再加入最短候选边，控制平均度。它是**受控稀疏空间图**，不是原始“距离小于30即连边”的原样扩展，也不是对所有固定半径随机几何图的抽样。

- Random：均匀随机坐标，整体连通。
- Regular：规则格点，非平方节点数使用不完整末行，整体连通。
- Clustered：五个空间簇，使用全局骨架使其连通。
- Disconnected：四个分离空间簇，仅允许簇内边，各簇连通，共四个连通分量。

默认平均度精确为6，选项2、4、6、8也精确满足目标。要求的是平均度，不限制每个节点的度；记录 `MaxDegree` 供复杂性解释。连通性约束会使低度网络接近树形。

工作负载采用受控合成分布，各规模保持一致：信任权重 U(0.2,1)、安全权重 U(0.5,1.5)、资源容量 U(1,20)，全部为正。每次重复重新生成位置及参数（规则位置固定、参数重新生成）。这些不是实测设备参数，也不代表将原稿数据无损扩充。

## 终止标准与结果解释

默认每轮结束检查固定策略剖面下的单节点最优偏离收益，用局部凹函数的一阶上界补偿局部数值误差。所有偏离在同一剖面计算。仅当最大节点收益上界不超过 `epsilon=1e-6`，才记为 `converged`。该标准给出每个节点同等精度的 epsilon-Nash 条件；同时报告总上界和平均上界。上界在精确算术下成立，代码以浮点数计算，并非区间算术证书。

默认最多500轮或120秒。时间上限在轮次/检查边界执行，可能超出一个轮次及检查的时间。`time_limit`、`iteration_limit` 都表示未在限额内满足条件，不能作为已收敛结果。运行时间包含初始/最终及中间误差检查，不包括数据生成、保存或绘图。图中的时间是终止时间；红叉表示至少一次重复未收敛，不能解释为收敛时间。

一轮为全部N个节点各更新一次。历史矩阵 `history` 的列依次为：完成轮数、累计秒数、最大偏离上界、总偏离上界、总安全效用、总分配资源。

## 计算复杂性

记 `d_i` 为节点度、`m=sum_i d_i=2|E|` 为有向分配变量数，`K` 为完成的循环轮数、`Q` 为误差检查次数。单个局部求解需要 O(d_i log(max(2,d_i))) 时间；增量维护监测输入需要 O(d_i)。因此求解及检查总时间阶为

`O((K+Q)*(N + sum_i d_i*log(max(2,d_i))))`。

每轮检查时 `Q=K+1`。平均度至多8意味着 `m<=8N`，因而可写为 `O((K+Q)*N*log(max(2,d_max)))`；只有最大度也有与N无关的上界时，才能进一步称每轮开销为 O(N)。不能仅根据平均度有界就省去最大度影响，也不能从收敛定理推断轮数K与N无关。

求解器的稀疏模型及工作向量需要 O(N+m+d_max) 存储；保存历史另需 O(Q)，保存所有试验摘要另计。网络生成的二跳候选矩阵可能更大，不包含在该求解器存储界中。`ModelBytes` 和 `AlgorithmArrayBytes` 是指定MATLAB变量的存储字节数，不是进程峰值内存。`SortWorkProxy` 是排序工作量代理，不是实际浮点操作数；`BestResponseCalls` 是更新与误差检查的局部求解调用总数。

## 通信开销：协议模型估算

当前代码在单台机器执行，不模拟传输延迟或网络栈。通信量是明确协议下的逻辑消息预算，**不是实际抓包测量**：

- 每次循环更新：每条有向邻居关系请求监测量、回复监测量、发送新分配，共3m条；另计N条调度消息。
- 每次固定剖面误差检查：邻居请求/回复共2m条；另计N条标量误差报告（汇总为最大值）。
- 初始化：2m条标量交换消息。
- 总量：`K*(3m+N)+Q*(2m+N)+2m`。
- 每条消息暂设32字节应用头、4字节标识、8字节标量，共44字节，可通过选项调整。

该预算假设调度与汇总可使用独立控制通道；它不包含控制消息多跳转发、重传、握手、额外传输层/链路层头或同步延迟。应在论文中明确假设，尤其是不连通拓扑的分量间汇总。若实际部署协议不同，应重新计算通信量；不要把此结果称为实测通信时延。

## 输出

- `scalability_trials.csv`：每次运行的规模、实际度、运行时间、轮数、误差、成功状态、计算计数及通信估算。
- `scalability_summary.csv`：每种配置的汇总，含终止时间标准差和收敛比例。
- `scalability_overview.pdf/.png/.fig`：六面板总览。
- `scalability_results.mat`：结果表和选项。
- 每案例MAT：参数配置、空间坐标和边、结果及收敛历史；完整模型可由种子和生成器再现。
- `best_response_validation.csv`：局部求解器对照验证。

论文报告应注明CPU、内存、MATLAB版本、重复次数、阈值、上限和是否有其他进程竞争资源。优先在空闲机器完成全量实验。随包预实验仅用于验证可运行性，不代替完整规模曲线。

补充输出：`convergence_histories.pdf/.png/.fig` 给出首个重复、首个平均度设置下三个代表规模的误差随轮数变化。`validate_scalability` 验证200和10000节点、平均度2和8的全部四种拓扑，并检查预实验的效用单调性、可行性、终止状态和计数一致性。

可由 `UpdateSeconds/Sweeps` 计算平均单轮更新时间；`GapSeconds/GapChecks` 为平均证书检查时间。这两者有助于区分每轮开销和迭代次数对总时间的影响。没有完成任何轮次的情况应排除除零操作。
